# Redes de Computadores

En este curso se estudió los fundamentos de las redes de computadores, incluyendo la arquitectura de red, protocolos de comunicación, y seguridad en redes.

Se usó Go para implementar algunos protocolos de red y realizar ejercicios prácticos relacionados con la comunicación entre computadores usando Wireshark para analizar el tráfico de red generado por los programas escritos en Go.

Tambien se hizo uso de herramientas como CISCO Packet Tracer para simular redes y practicar la configuración de dispositivos de red como routers y switches.
