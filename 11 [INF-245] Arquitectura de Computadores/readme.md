# Arquitectura de Computadores

En este curso se estudió los fundamentos de la arquitectura de computadores, incluyendo el diseño de procesadores, memoria, y entrada/salida.

Logisim se utilizó para simular circuitos digitales. Descargalo desde la carpeta "Logisim" desde este mismo lugar.

Se uso Verilog para describir hardware a nivel de registro. Se uso el simulador en EDAPlayground para probar los diseños de hardware.
