# Sistemas Distribuidos

En este curso se estudió los fundamentos de los sistemas distribuidos, incluyendo la comunicación entre procesos, sincronización, y tolerancia a fallos en sistemas distribuidos. Se usó Go para implementar algunos ejercicios prácticos relacionados con la comunicación entre procesos usando gRPC para la comunicación remota entre servicios distribuidos y Docker para desplegar aplicaciones distribuidas en contenedores en multiples máquinas virtuales.
