# Informatica Teorica

En este curso se estudió los fundamentos de la informática teórica, incluyendo la teoría de autómatas, gramáticas formales, y complejidad computacional. Se aprendió a diseñar y analizar autómatas finitos, autómatas de pila, y máquinas de Turing, así como a clasificar problemas según su complejidad computacional usando clases como P, NP, y NP-completo.

---

Se nos enseñó a usar JFLAP para crear y simular autómatas, gramáticas, y demás cosas relacionadas con la teoría de la computación.

Para poder abrir los archivos `.jff`, debes instalar JFLAP. Descarga JFLAP desde la carpeta "JFLAP" que se encuentra aqui mismo.
