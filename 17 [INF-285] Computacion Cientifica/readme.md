# Computación Científica

En este curso se estudió el uso de herramientas computacionales para resolver problemas científicos que involucran grandes cantidades de datos o cálculos complejos, como la simulación numérica, el análisis de datos, y la visualización científica. Se usó Python con bibliotecas como NumPy, SciPy, Matplotlib, y Jupyter Notebooks para realizar los ejercicios y proyectos del curso.
