# Estructuras de Datos

En este curso se estudió los fundamentos de las estructuras de datos, incluyendo listas enlazadas, pilas, colas, árboles, grafos, y tablas hash. Se implementaron estas estructuras de datos en C y se aplicaron para resolver problemas algorítmicos relacionados con la manipulación de datos.
