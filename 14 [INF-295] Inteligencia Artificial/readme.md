# Inteligencia Artificial

En este curso se realizó un trabajo individual que consistió en investigar problemas y algoritmos que se relacionan con los inicios del estudio de la inteligencia artificial, y luego implementar un programa que resuelva uno de esos problemas.

## 2D Strip Packing Problem

El problema de empaquetamiento de tiras en 2D (2D Strip Packing Problem) es un problema de optimización combinatoria que consiste en empaquetar un conjunto de rectángulos dentro de una tira de ancho fijo y longitud infinita, con el objetivo de minimizar la altura total utilizada.

Este problema es NP-hard, lo que significa que no existe un algoritmo eficiente para resolverlo exactamente en tiempo polinomial.

El trabajo consiste en buscar e implementar un algoritmo heurístico para resolver este problema.
