# Bases de Datos

En este curso se estudian los fundamentos de las bases de datos relacionales y SQL, incluyendo conceptos como diseño de bases de datos, normalización, y consultas SQL. Se aplican estos conceptos a través de tareas y proyectos prácticos.

En la Tarea 1 se ve SQL plano, y en la Tarea 2 se ve los conceptos aplicados a un proyecto de desarrollo web con PHP y MySQL.
